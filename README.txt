SYSTEM FAILURE — інтерактивна домашня гра

Відкрийте index.html на двох пристроях (або у двох вкладках одного браузера).
Гравчиня: вкладка «ГРАВЧИНЯ»; оператор: вкладка «ОПЕРАТОР».

ВАЖЛИВО: без хмарного налаштування синхронізація працює лише між вкладками одного браузера/пристрою. Для двох різних телефонів налаштуйте Firebase Realtime Database (інструкції нижче). Сам файл index.html на телефоні може потребувати відкриття через HTTPS-хостинг (GitHub Pages, Netlify Drop або Firebase Hosting).

FIREBASE SETUP:
1. Створіть проєкт на console.firebase.google.com.
2. Authentication > Sign-in method > Anonymous > Enable.
3. Build > Realtime Database > Create database.
4. Rules (для приватної домашньої гри; кожен авторизований анонімно користувач може читати/писати кімнати, тому не використовуйте для конфіденційних даних):
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
5. Project settings > Your apps > Web app > Firebase config. Вставте значення у файл config.js.
6. Завантажте всі файли папки system_failure на статичний HTTPS-хостинг.
7. На обох телефонах відкрийте ту саму адресу і введіть однаковий код кімнати (складний випадковий код, не 1234). Один обирає роль «Оператор», інший — «Гравчиня».

Це домашня гра, не захищена від гравця з технічними навичками. Не використовуйте реальні паролі або особисті дані.

ПІДГОТОВКА:
Етап 1: записка «СВІДОК» на дні однієї тарілки.
Етап 2: на стільці «Ш», ноутбуці «А», холодному чайнику «Ф», столі «А»; у шафі записка «АРХІВ».
Етап 3: світильник, обличчям до ваших фото; рух: вперед 2, праворуч 1, ліворуч 1, ліворуч 1, вперед 3, ліворуч 4, праворуч 1. Повороти на 90 градусів, потім кроки вперед. Праворуч у кінці — коробочка з косметикою, записка «КОНТРОЛЬ».
Етап 4: роздрукуйте fragments.html, виріжте 4 фрагменти й закріпіть їх біля предметів: подушка, рушник, книга, взуття. Три фрагменти (A, B, C) утворюють квадрат, D — зайвий. На сайті правильний предмет — «Взуття». За потреби змініть назви у config.js.
Етап 5: окремий тимчасовий локальний обліковий запис ПК, пароль «8», дзеркало з 8 панелей; «Менталіст», сезон 2, серія 5, 18:16–18:25, у шухляді «ОЧЕВИДЕЦЬ». Перевірте час на власній версії серії.
Етап 6: записка з романтичним посланням увесь час у вас. Пароль вголос «ТИ ПАЦЮК». Завершіть гру з адмінпанелі.

Оператор може вручну приймати відповіді, запускати наступні етапи, активувати MIRROR.exe, надсилати підказки/повідомлення, ставити паузу на таймері, завершувати гру.
